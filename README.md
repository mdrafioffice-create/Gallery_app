# Pixel Dash – an original side-scrolling platformer (Flutter)

Play as Pip, a little round hero. Run and jump across platforms, leap over pits,
stomp the purple Spikeys, collect coins, and reach the flag at the end of each level.

Play in landscape. On-screen buttons: ◄ ► to move (bottom left), JUMP (bottom right).
Hold jump for a higher leap. Three lives; fall in a pit or get hit and you lose one.

This is an original game — not based on any existing game or characters.
